# Project Memory

## Core
Dark brand site. BG #090909, accent #FF5000, text #F5F5F5, muted #9F9F9F, border #2E2E2E.
Bebas Neue headlines, Inter body, JetBrains Mono overlines/accent.
All colors mapped to CSS vars in index.css as HSL. Never use raw hex in components.
Never use dividers (border-top, hr, separators) between sections.
Headings always font-weight normal, never bold.
Box/card titles always Title Case, never all caps.
