---
name: Box titles use Inter and Title Case
description: Card/box titles must always use Inter (font-body), Title Case, never headline font or all caps
type: constraint
---
All titles inside cards/boxes must use Inter (font-body) in Title Case. Never use the headline font (Bebas Neue) or all-caps for box titles, even if the user's pasted sample text uses a display font or caps. **Why:** User explicitly requested this as a consistent rule.
